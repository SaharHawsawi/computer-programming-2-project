# computer-programming-2-project
a simple store management system called Tech Store, containing products and customers, and displays information about the organization, its products, and its customers in the console.
# About the project
a Java-based project developed as part of the Programming 2 course. it demonstrates important Object-Oriented Programming (OOP) concepts by modeling a simple organization that contains products and customers using four classes: App, Product, Customer, and Organization. The application provides a practical example of how classes, objects, constructors, encapsulation, arrays of objects, and method overriding can work together to represent a real-world business scenario.

The project consists of four main classes:
* App: The entry point of the program, responsible for creating objects and executing the application.
* Product: Represents products and their information, including ID, name, and price.
* Customer: Represents customers and their personal and contact information.
* Organization: Represents the store and maintains references to its products and customers.
# Project Objectives
* Apply Object-Oriented Programming principles using Java.
* Understand how classes and objects represent real-world entities.
* Implement constructors to initialize objects.
* Practice encapsulation.
* Override the toString() method to display meaningful object information.
* Understand relationships between classes.
* Improve code organization, readability, and maintainability.
# Features
🏢 Organization Management : Create an organization with its own identification number, name, and address.
The organization also maintains arrays of products and customers associated with it.

📦 Product Management :

Each product contains:

* A unique product ID.
* A product name.
* A product price.

👥 Customer Information

Each customer contains:

* A customer ID.
* A full name.
* An address.
* A mobile number.
* An email address.

Arrays of Objects : Store multiple products and customers in arrays to maintain collections of related objects and iterate through them when displaying information.

Formatted Console Output : Display organization details, product information, and customer information using customized toString() methods.

🔒 Encapsulation : Use private instance variables and public getter and setter methods to manage access to object attributes.
# ⚙️ How It Works
1. Create products: Instantiate two products, a Laptop and a Mouse.
2. Create customers: Instantiate two customers with their identification and contact information.
3. Create arrays: Store the product objects in a Product[] array and the customer objects in a Customer[] array.
4. Create the organization: Instantiate Organization with its details and both arrays.
5. Display the organization: Print its information, including all associated products and customers.
6. Display individual objects: Print the first product and the first customer separately.
# 🛠️ Technologies Used
* Java — The primary programming language used to develop the application.
* Object-Oriented Programming (OOP) — Used to model the organization, products, and customers as separate classes.
* Java Arrays — Used to store collections of product and customer objects.
